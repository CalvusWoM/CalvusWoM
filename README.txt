SotS Calculator v1.2 — Offline-Web-App

Öffne index.html durch Doppelklick im Browser. Keine Installation, kein Internet erforderlich.
Erfasse Wrestlerdaten und klicke „Zur Rangliste hinzufügen“. Die Rangliste bleibt lokal in diesem Browser gespeichert.
„Zurücksetzen“ löscht nur aktuelle Eingaben. Kandidaten werden über die Rangliste bearbeitet, gelöscht, als CSV exportiert oder per JSON gesichert und wieder importiert.

Scoring: Championship 30, Trophäen 25, Siegquote 20, Workrate 10, Rekorde 10, Season-Einfluss 5.
Tiers: Jobber (0), Undercarder (15), Rising Star (30), Mid Carder (45), Top Guy (60), SotS Kandidat (75), Hall of Famer (90).
WrestleMania Battle Royal: 3 Rohpunkte = 1,5 Gesamtpunkte, solange der Trophäen-Cap nicht erreicht ist.
